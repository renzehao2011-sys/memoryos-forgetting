## 2. 代码现状（三个月后最容易被搞混的地方）

### 2.1 τ 表已经变了含义

```python
TYPE_TAU_DAYS = {
    "episode": 21,
    "knowledge": 90,
    "preference": None,   # P1 起走 supersede，不吃 τ
    "identity": None,     # freeze（stable）/ supersede（changing），都不吃 τ
}
CHANGING_IDENTITY_TAU_DAYS = 180.0   # 已废弃，仅为兼容旧 import 保留，score 不再读
```

**看到 `preference=90` 或 `changing=180` 的说法都是 P1 之前的旧文（M6 报告、交付报告 §5.1）。**

### 2.2 三种机制

| 机制 | 判定 | 怎么“消失” | 相关 API |
|---|---|---|---|
| `decay` | episode / knowledge | 分数随 τ 指数衰减 → full/gist/none | `mechanism_of()`, `tau_days_for()` |
| `supersede` | preference、identity+changing | 被新事实覆盖时写 `valid_to`；召回层直接过滤 | `expire_old_facts()`, `restore_expired()` |
| `freeze` | identity(stable) | 只能人工改 | — |

`lifespan_days`（单条寿命，天）：
- decay 类：覆盖 type 级 τ（**以后不同寿命别再新增 type**）；
- supersede 类：当作保质期，超期只打 `stale_since` + 审计 `action=stale`，**不改 state、不降档、不删除**，等人工复核。

### 2.3 关键函数位置

```
memoryos/scoring.py            compute_score / tier_of / make_gist / mechanism_of / is_stale
memoryos/retriever.py          _drop_invalid（正确性过滤，与开关无关）/ _apply_tiers（三档）
memoryos/consolidate.py        dedupe / recompute_states（cold 仅 decay 类）/ restore_expired
memoryos/consolidate_llm.py    find_conflict_candidates（同层级才配对）/ expire_old_facts / 日小结
memoryos/archive.py            list_pending / confirm_archive（唯一写 archived 的入口）
run_consolidate.py             CLI：--dry-run / --steps / --confirm-archive / --restore
```

## 6. 坑（都踩过，别再踩）

1. **`super_admin:terminal` 会卡死在 pager。** `git log` 之类输出长的命令进了 `less`，此后所有 terminal 调用全部超时，且 `pkill less` 也救不回来（底层 `bash -il` 被杀后会话不重建）。**下次先 `export GIT_PAGER=cat` / `PAGER=cat`。**
2. **工作流节点也走 `terminal`**，终端一卡，无人值守执行器一起废。所以这次后台跑测试改用 `setsid nohup ... > log`，靠读文件回来看结果。
3. **`code_runner` 自带的 python 是空环境**（`/root/.code_runner/py`，没有 openai/faiss/numpy）。跑项目代码必须显式用 `/usr/bin/python3`。
4. **非交互 shell 里 `.bashrc` 会被开头 `[ -z "$PS1" ] && return` 挡掉**，`source /root/.bashrc` 不会导出 `DASHSCOPE_API_KEY`。用 §4.1 那行 `sed` 直接抽。
5. **`__pycache__` 没被 `.gitignore` 覆盖**，提交时用显式文件列表，别 `git add -A`。
6. **`m6_grid.py --sweep` 会重写 `results/m6_grid.json`**（即使只是看）。
7. **`test_m3_idempotent.py` 会写 `/home/m0_baseline/_m3_idem`**（拷贝自 `data_m2_scored_backup`）；想彻底隔离就改 `WORK` 到 `/tmp`。
8. **`DASHSCOPE_API_KEY` 曾在一次调试输出里被打印**，建议轮换后再用。
